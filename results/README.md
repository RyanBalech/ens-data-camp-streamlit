# Evaluation evidence

`evaluation.json` contains aggregate results generated by `scripts/evaluate.py`
from a seed-42 sample of 60,000 original training observations.
Every sampled observation receives one held-out prediction in three-fold
GroupKFold validation grouped on TS. No raw observations or individual prediction
records are published here. The artifact records input SHA-256 hashes, fold sizes,
date overlap checks, package versions, model parameters and confusion counts at
101 thresholds.

This is a new bounded CPU experiment, not a reproduction of the original report's
GPU CatBoost run. Feature calculations are row-local. Missing historical return
and volume values use zero; other numeric imputation is fitted on each training
fold. Logistic preprocessing is trained on that fold too. Group-relative
transformations and population clipping from the old notebook are omitted.

CatBoost importance is the average PredictionValuesChange across the three
trained models. It is not SHAP, causal attribution or a validation permutation
score. Threshold exploration reuses these validation predictions and must not be
reported as independent test-set optimization.

The original report's model comparison and leaderboard results are shown in a
separately labeled historical section. Its grouped/stratified validation
descriptions conflict. This experiment's protocol is explicit and executable.

To regenerate in the same Python environment after building the app image:

```sh
docker run --rm -v "/absolute/path/to/repository:/app" -v "/absolute/path/to/data:/data:ro" ens-data-camp sh -c "pip install -r requirements-model.txt && python scripts/evaluate.py --features /data/X_train_9xQjqvZ.csv --targets /data/y_train_Ppwhaz8.csv"
```

Use absolute host paths on Windows too. This mounts the repository so the
generated file persists. Run from a trusted repository; training is offline and
does not happen when the professor opens Streamlit. The model dependency lock is
separate so the serving container stays small and fast.
